# MP1 report

The English report uses a two-column proceedings-style layout. It has no
reference section. All figures are generated through the original `runs/plot.py`
functions, with adapted paths, English labels, and figure size.

Compile `report.tex` from this directory with pdfLaTeX or XeLaTeX. Keep the
`figures/` directory beside it. Upload the source and the three figures together
to Overleaf, or use the source archive.

Regenerate the images with `python generate_figures.py` (requires Matplotlib).
The original plotting script is unchanged. Add your name and student ID to the
author line if required for submission.
